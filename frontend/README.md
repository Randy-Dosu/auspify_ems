# Auspify EMS — frontend

React + Vite client for the Auspify EMS API.

- `npm install`
- `npm run dev` — starts Vite on port 5173 and proxies `/api` to Flask on port 5000.
- `npm run build` — production build.
- `npm run lint` — oxlint.

See the [root README](../README.md) for full setup, API reference, and
testing instructions.
